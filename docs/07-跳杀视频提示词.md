# 跳杀视频提示词

这份文件是给项目作者用的：**把下面的提示词喂给豆包（视频生成），出片后按文件名丢进项目即可。**

项目里的跳杀现在是「静态惊吓图 + 程序抖动」兜底，**视频一条都还没有**。
丢进 `Assets/Video/Jumpscares/` 之后还需要接一次代码（见文末），才会真正播视频。

## 〇、先看这段：通用规则

### 1. 这四个角色长什么样（**最重要的锚点**）

豆包不认识我们的角色，光靠文字描述一定会画成别的卡通动物。
**所以强烈建议走「图生视频」：拿项目里现成的图当首帧 / 参考图。**

| 角色 | 拿哪张图当参考 | 路径 |
|---|---|---|
| 奶龙 `nailong` | `char_nailong_jumpscare.png`（大张嘴那张，最接近成品） | `Assets/Art/Characters/` |
| 牛来 `niulai` | `char_niulai_stare.png` | 同上 |
| 袋鼠 `daishu` | `char_daishu_stare.png` | 同上 |
| 噜噜 `lulu` | `char_lulu_stare.png` | 同上 |

各角色的外观特征（也写进提示词里，防止跑偏）：

- **奶龙**：奶油黄到芥末黄的**圆润头身一体**，没有明显脖子；嘴张得极大、占画面下半，
  上下各一排**奶白色钝齿**，口腔是深红棕色；眼睛细长、上眼睑重、笑眯成月牙状带白色高光。
  表面光滑哑光，没有毛发纹理。
- **牛来**：**橙棕色牛头**，额头有皱褶、一对深色粗眉；大眼、棕色瞳孔 + 白眼球；
  宽大的浅米色口鼻，两个深色鼻孔；两侧尖耳、耳内浅粉；下巴浅米色。
- **袋鼠**：**亮柠檬黄**、腹部偏橙黄的大肚子；长耳竖立，深棕近黑的圆鼻子，
  圆眼（白眼球 + 棕瞳）；坐姿、短前肢、粗尾巴；哑光橡胶玩具质感。
- **噜噜**：**黄色大圆头**，**下半张脸（口鼻区）是橙色**，像戴了半张面具；
  头顶正中一颗**小橘子**（橙色小圆球 + 一片绿叶），两侧各一只小尖角；
  眼睛细长、黑色大瞳孔；平时嘴是一条不高兴的细弧线；脖子上挂**奶油色小挎包**（包上有张笑脸）。

### 2. 风格块（四条都拼上它）

**中文**

```
光滑的 3D 玩具质感，哑光橡胶 / 黏土玩偶表面，圆润的大块面造型，柔和的棚拍打光，
没有毛发纹理、没有布料细节。单色纯净背景（纯黑）。
画面里只有这一个角色，没有别的动物、没有人。
没有文字、没有字母、没有水印、没有 logo、没有边框、没有 UI。
```

**English**

```
Smooth 3D toy look, matte rubber / clay figure surface, big rounded simple shapes,
soft studio lighting, no fur texture, no fabric detail. Plain solid black background.
Only this one character in frame — no other animals, no people.
No text, no letters, no watermark, no logo, no border, no UI.
```

> **为什么要求纯黑背景**：游戏里跳杀是一层全屏黑幕 + 把画面怼上去，
> 纯黑背景能和黑幕无缝接起来；出成别的颜色会看到一圈明显的方框边。

### 3. 镜头与动作（四条通用）

```
第一人称视角被它正面怼脸：镜头正对着它的脸，超近距离特写，脸充满整个画面、不留边距，
广角镜头带来的轻微透视变形。它朝镜头猛扑过来，动作又快又突然，
之后持续张嘴嘶吼、头部剧烈左右甩动。镜头本身有轻微手持抖动。
一镜到底，不要转场、不要镜头拉远、不要换角度。
```

**English**

```
First-person view of it lunging straight at the camera: extreme close-up of its face,
filling the entire frame edge to edge, slight wide-angle perspective distortion.
It snaps toward the lens fast and suddenly, then keeps its mouth wide open snarling
while the head shakes violently side to side. Subtle handheld camera shake.
One continuous shot — no cuts, no pull-back, no angle change.
```

### 4. 时长与音频

| 项 | 要求 | 说明 |
|---|---|---|
| 时长 | **豆包出 5 秒就行** | 游戏里只播前 **2.5 秒**，多出部分我截掉，**你不用自己剪** |
| 分辨率 | 1080p / 1920×1080 **横屏** | 游戏是 16:9 |
| 比例 | **16:9** | 出成竖屏或方形就没法用 |
| 音频 | **要，内嵌** | 一声尖利的怪叫 / 金属刮擦 + 低频冲击 |
| 不要 | 不要配乐、不要人声台词、不要片头片尾 | 音乐会盖掉游戏自己的音轨 |

> 音频这条特别重要：**游戏目前没有跳杀音效**（`AudioManager` 里只有开关门 / 脚步 / 断电这些）。
> 视频内嵌的这声叫，就是玩家听到的那一声。

### 5. 通用负面提示词

```
写实照片, 真人, 人类, 血腥, 断肢, 尖牙利齿的怪物化, 毛发, 布料,
文字, 字母, 水印, logo, 边框, UI, 白天, 明亮背景, 多角色, 场景, 房间, 道具,
镜头拉远, 转场, 分镜, 慢动作, 卡通线条描边, 廉价 3D 渲染感
```

```
photorealistic, real person, human, gore, blood, dismemberment, monstrous fangs,
fur, fabric, text, letters, watermark, logo, border, UI, daytime, bright background,
multiple characters, scenery, room, props, camera pull-back, cuts, storyboard,
slow motion, cel-shaded outline, cheap 3D render look
```

> **别把它画成恐怖怪物。** 这个项目的调性是**可爱反差恐怖** ——
> 角色外形保持圆润可爱（这是「奶龙」这个 IP 的本体），
> 靠**突然逼近 + 超近距离 + 张嘴 + 抖动 + 尖叫**吓人，而不是靠改成尖牙利齿的怪物。
> 这一点在 `docs/04-设计决策.md` 里定过稿，别跑偏。

## 六、代码侧现状（这条是给我自己看的，你不用管）

⚠️ **目前 `PrototypeScene` 根本没有接 `VideoPlayer`。**
`Assets/Scripts/UI/PrototypeScene.cs` 第 1496 行的注释写着
「（占位：全屏红 + 大字抖动。等 mp4 就绪后换成 VideoPlayer）」——
也就是说**视频做好了也得先把这段代码改掉，否则不会播**。

接的时候要注意：

- Unity 的 `VideoPlayer` 播 `mp4` **不支持透明通道**，所以视频背景用纯黑（见 §0.2）
- `Assets/Video/Jumpscares/` 是**普通资源目录**，运行时不能用 `Resources.Load` 直接取；
  要么挪进 `Assets/Resources/`（会被全量打进包体），要么走 `StreamingAssets` + `url` 赋值
- 播完要 `Stop()` 并释放，否则第二次跳杀会卡在上一帧
- **兜底链不能丢**：视频缺失 / 解码失败时，仍然退回现有的静态惊吓图 + 抖动
