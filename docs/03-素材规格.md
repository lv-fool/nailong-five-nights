# 03 · 素材规格

> 美术与音频由你自己提供。这份文档说明**按什么规格交**，代码才能直接用上。
> 一句话原则：**尺寸、格式、命名都固定，我按命名规则写代码，你按规则丢文件，不用来回沟通。**

---

## 一、静态画面

| 项 | 要求 |
|---|---|
| 基准分辨率 | **1920 × 1080**（16:9）。更高分辨率按同比例（如 2560×1440、3840×2160） |
| 格式 | **PNG-24**，需要透明的地方保留 alpha 通道 |
| 色彩空间 | sRGB。**光影直接画进图里** —— 不要指望引擎打光，Built-in 管线不做实时光照 |
| 不要 | 不要 JPG（恐怖游戏的暗部会有明显压缩块），不要带水印 |

### 需要哪些图

**1. 办公室视角**（放 `Assets/Art/Backgrounds/`）

FNAF 的做法是左右转头各有若干中间帧，转动时逐帧切换做出"转头"的感觉。

- `bg_office_front.png` —— 正前方（看监控时的底图）
- `bg_office_left_01.png` ~ `bg_office_left_03.png` —— 向左转头的过程帧（可选，只给 1 张也行）
- `bg_office_right_01.png` ~ `bg_office_right_03.png` —— 向右转头
- 每侧门两个状态：`bg_office_left_door_open.png` / `bg_office_left_door_closed.png`
  （如果门是叠层，也可以做成单独的 `ui_door_left_open.png` 贴在上层）

**2. 监控画面**（放 `Assets/Art/Monitoring/`）

每个机位一张，命名 `mon_<机位编号>.png`，例如：

- `mon_cam1a.png`、`mon_cam1b.png`、`mon_cam2.png`……

> 监控的"信号噪点"效果**不用画**，我用 shader 叠加。你只要给干净的画面。

**3. 角色**（放 `Assets/Art/Characters/`）

命名 `char_<角色名>_<状态>.png`：

- `char_nailong_idle.png` —— 静态站立
- `char_nailong_stare.png` —— 直视镜头（惊吓用）
- `char_nailong_jumpscare.png` —— 跳杀特写（建议比 1920×1080 更大，铺满屏幕用）

**4. UI 元素**（放 `Assets/Art/UI/`）

命名 `ui_<类型>_<名称>_<状态>.png`：

- 按钮：`ui_btn_door_normal.png` / `ui_btn_door_hover.png` / `ui_btn_door_pressed.png`
- 电量条：`ui_power_bar_bg.png` + `ui_power_bar_fill.png`（可拉伸的九宫格图）
- 时间/夜晚数：可以只用文字，不必出图

## 二、音频

| 项 | 要求 |
|---|---|
| 格式 | **WAV**（无损源）或 **OGG Vorbis**。别给 MP3 —— 循环点会有空隙 |
| 采样率 | 44.1 kHz |
| 循环音 | 必须**无缝循环**（首尾能接上），否则会听到"咔哒" |
| 长度 | 环境音建议 30 秒以上再循环，避免听出周期 |

### 需要哪些音频

**环境音**（`Assets/Audio/Ambient/`）—— 恐怖氛围的主力，比画面重要

- `amb_fan_loop.ogg` —— 办公室风扇（持续底噪，必须有无缝循环）
- `amb_electric_hum.ogg` —— 电流嗡鸣
- `amb_distant_metal.ogg` —— 远处金属声（偶发）

**音效**（`Assets/Audio/SFX/`）

- `sfx_door_close.ogg` / `sfx_door_open.ogg`
- `sfx_light_on.ogg` / `sfx_light_off.ogg`
- `sfx_camera_switch.ogg` —— 切换监控
- `sfx_footstep.ogg` —— 敌人逼近的脚步声（**这个最关键，是玩家的主要信息来源**）
- `sfx_jumpscare.ogg` —— 跳杀尖叫
- `sfx_power_out.ogg` —— 断电

**音乐**（`Assets/Audio/BGM/`）

- `bgm_menu.ogg` —— 主菜单
- `bgm_night_end.ogg` —— 撑过一夜

## 三、如果素材还没画

**先不用等。** 玩法验证阶段我可以用纯色块、几何图形和纯代码画的占位图跑通全部逻辑，
你之后把同名文件丢进对应目录，代码不用改一行。

占位阶段建议优先准备的是**音频**：FNAF 类游戏的紧张感七成来自声音，
有脚步声和环境底噪，玩法立刻就能"试出感觉"。

## 四、交付方式

直接把文件按上面的目录和命名放进去即可。放好后告诉我，我写代码接上。

有拿不准的地方（比如某个状态需要几张图），先问，别自己猜着画一堆。
