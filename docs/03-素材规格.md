# 03 · 素材规格

> 美术与音频由你自己提供。这份文档说明**按什么规格交**，代码才能直接用上。
> 一句话原则：**尺寸、格式、命名都固定，我按命名规则写代码，你按规则丢文件，不用来回沟通。**
>
> 设计定稿见 `docs/04-设计决策.md`。本文件只讲「交什么、怎么交」。

---

## 一、静态画面

| 项 | 要求 |
|---|---|
| 基准分辨率 | **1920 × 1080**（16:9）。更高分辨率按同比例（如 2560×1440、3840×2160） |
| 格式 | **PNG-24**，需要透明的地方保留 alpha 通道 |
| 色彩空间 | sRGB。**光影直接画进图里** —— Built-in 管线不做实时光照 |
| 不要 | 不要 JPG（恐怖游戏的暗部会有明显压缩块），不要带水印 |

### 1. 办公室背景（放 `Assets/Art/Backgrounds/`）

**背景图不含门**（门是单独的叠层，见下）：

- `bg_office_front.png` —— 正前方
- `bg_office_left_01.png` ~ `bg_office_left_NN.png` —— 向左转头的过程帧
- `bg_office_right_01.png` ~ `bg_office_right_NN.png` —— 向右转头的过程帧

> **帧数随你。** 只给最侧 1 张，或者给 3~5 张，都行 ——
> 代码读目录、**有几张用几张**。给得越多，转头越顺。

### 2. 门（叠层门片，放 `Assets/Art/UI/`）

门不做进背景里，而是单独的透明 PNG 盖在上层，这样才能滑入滑出：

- `ui_door_left_open.png` / `ui_door_left_closed.png`
- `ui_door_right_open.png` / `ui_door_right_closed.png`

> ⚠️ 门片的透视要对齐背景里门框的位置，**请对着 `bg_office_left_*` / `bg_office_right_*` 画**。

### 3. 监控画面（放 `Assets/Art/Monitoring/`）

**照官方平面图做 11 个机位，但只需画 10 张** —— 厨房照官方**只有声音、没有画面**，
切过去是一片黑，不用给图。文件名照官方 CAM 编号：

| 文件 | 内容 | 文件 | 内容 |
|---|---|---|---|
| `mon_1a.png` | 舞台 | `mon_4a.png` | 东走廊 |
| `mon_1b.png` | 餐厅（大厅） | `mon_4b.png` | 东走廊转角 |
| `mon_1c.png` | 海盗湾 | `mon_5.png` | 后台 |
| `mon_2a.png` | 西走廊 | `mon_7.png` | 厕所 |
| `mon_2b.png` | 西走廊转角 | ~~`mon_6.png`~~ | **厨房 —— 不用画**（黑屏） |
| `mon_3.png` | 储藏室 | | |

> **缺哪张哪张退回色块 + 机位名**，不会报错 —— 所以可以一张张慢慢补，
> 先画最要紧的那几个（1B 餐厅、2A 西走廊、4A 东走廊是玩家最常看的）。
> 监控的「信号噪点」效果**不用画**，我用 shader 叠加。你只要给干净的画面。
> **厨房要的是声音，不是图** —— 如果要做，给我一条「厨房环境音」放 `Audio/SFX/` 就行。

### 4. 角色（放 `Assets/Art/Characters/`）

四个角色，每个**三张**；奶龙多一张**断电专用**，噜噜多三张**表情**：

| 角色 | 代号 | 需要的文件 |
|---|---|---|
| 奶龙 | `nailong` | `char_nailong_idle.png` / `char_nailong_stare.png` / `char_nailong_jumpscare.png` / `char_nailong_blackout.png` |
| 牛来 | `niulai` | `char_niulai_idle.png` / `char_niulai_stare.png` / `char_niulai_jumpscare.png` |
| 袋鼠 | `daishu` | `char_daishu_idle.png` / `char_daishu_stare.png` / `char_daishu_jumpscare.png`（**已有前两张**，跳杀暂用 `_stare` 兜底） |
| 噜噜 | `lulu` | `char_lulu_idle.png` / `char_lulu_stare.png` / `char_lulu_peek.png` / `char_lulu_startled.png` / `char_lulu_angry.png`（跳杀沿用 `_stare`） |

- `_idle` —— 静态站立（出现在监控 / 门口）
- `_stare` —— 直视镜头。门口一律用 `_idle`（站姿），所以它主要在**跳杀兜底**时出场
  （没出专属跳杀图就退到这张），也用在正前方逼近的噜噜身上
- `_peek` —— **只有噜噜有**：从门外探出头。噜噜是被灯照到才现形的，
  所以门口显示的是这张而不是站姿
- `_startled` —— **只有噜噜有**：受惊（瞪眼张嘴、带汗滴）。盯着它看的时候换这张
- `_angry` —— **只有噜噜有**：怒视（眯眼抿嘴）
- `_jumpscare` —— 跳杀特写，**建议比 1920×1080 更大**，铺满屏幕用；
  同时兼作**视频没就绪时的兜底画面**
- `_blackout` —— **只有奶龙有**：断电后来「收电费」的那张（捧腹大笑）。
  这张会被反复闪烁显示，**背景越干净越好**（纯色或全透明），别画场景进去。
  没给就退回用 `_jumpscare`

> **缺哪张都能跑**：取图统一走 `CharacterArt.Get(pose)`，缺了就退 `_stare`、再缺退 `_idle`、
> 全缺退回色块剪影。噜噜的 `_jumpscare` 没给，跳杀会自动用 `_stare`。

共 15 张（噜噜的跳杀那张可省）。

### 5. UI 元素（放 `Assets/Art/UI/`）

命名 `ui_<类型>_<名称>_<状态>.png`：

- 按钮（门 / 灯 / 监控各一组）：`ui_btn_door_normal.png` / `_hover.png` / `_pressed.png`
- 电量条：`ui_power_bar_bg.png` + `ui_power_bar_fill.png`（可拉伸的九宫格图）
- 时间 / 夜晚数：可以只用文字，不必出图

## 二、跳杀视频（放 `Assets/Video/Jumpscares/`）

**每个敌人一条**，共 4 条：

- `char_nailong_jumpscare.mp4`
- `char_niulai_jumpscare.mp4`
- `char_daishu_jumpscare.mp4`
- `char_lulu_jumpscare.mp4`

| 项 | 要求 |
|---|---|
| 容器 / 编码 | **MP4 / H.264**（Unity VideoPlayer 兼容性最好） |
| 分辨率 | 1920 × 1080 |
| 时长 | **2 ~ 3 秒** |
| 音频 | **内嵌**（尖叫音效直接混进视频） |
| 不要 | 不要片头片尾、不要黑边 |

> **做不出来也没关系**：我会先用上面的 `_jumpscare.png` 加程序抖动兜底，不会黑屏。
> 哪条视频做好了丢进目录，那条就自动改播视频。

## 三、音频

| 项 | 要求 |
|---|---|
| 格式 | **WAV**（无损源）或 **OGG Vorbis**。别给 MP3 —— 循环点会有空隙 |
| 采样率 | 44.1 kHz |
| 循环音 | 必须**无缝循环**（首尾能接上），否则会听到「咔哒」 |
| 长度 | 环境音建议 30 秒以上再循环，避免听出周期 |

**环境音**（`Assets/Audio/Ambient/`）—— 恐怖氛围的主力，比画面重要

- `amb_fan_loop.ogg` —— 办公室风扇（持续底噪，必须无缝循环）
- `amb_electric_hum.ogg` —— 电流嗡鸣
- `amb_distant_metal.ogg` —— 远处金属声（偶发）

**音效**（`Assets/Audio/SFX/`）

- `sfx_door_close.ogg` / `sfx_door_open.ogg`
- `sfx_light_on.ogg` / `sfx_light_off.ogg`
- `sfx_camera_switch.ogg` —— 切换监控
- `sfx_footstep.ogg` —— 敌人逼近的脚步声（**这个最关键，是玩家的主要信息来源**）
- `sfx_jumpscare.ogg` —— 跳杀尖叫（视频若已内嵌音频，这条可省）
- `sfx_power_out.ogg` —— 断电
- `sfx_power_out_music.ogg` —— **断电音乐盒**。原版 FNAF 1 断电时放的是托雷多进行曲
  （比才《卡门》1875，公有领域），**现在这条是我合成的八音盒版**
  （`tools/gen_power_out_music.py`）。有更好的素材同名替换即可 ——
  演出里的音乐段长度会自动跟着音频长度走，代码不用改。
  要求：**不循环**、末尾留一点衰减尾巴

**音乐**（`Assets/Audio/BGM/`）

- `bgm_menu.ogg` —— 主菜单
- `bgm_night_end.ogg` —— 撑过一夜

## 四、素材现状

**先不用等。** 开发阶段已经放了一套占位素材，把全部逻辑跑通了；你之后把同名文件丢进对应目录，
再跑一次菜单「奶龙 → 5. 接入素材」即可替换，代码不用改一行。

### 已就位的真素材

| 类别 | 内容 | 来源 |
|---|---|---|
| 角色立绘 4 张（奶龙） | `char_nailong_idle` / `_stare` / `_jumpscare` / `_blackout` | 绿子提供 |
| 角色立绘 5 张（噜噜） | `char_lulu_idle` / `_stare` / `_peek` / `_startled` / `_angry` | 前三张绿子提供，后两张以 `_stare` 为参考图生成 |
| 断电音乐 | `sfx_power_out_music.wav`（八音盒版托雷多进行曲） | 程序合成（`tools/gen_power_out_music.py`，曲谱为公有领域） |

奶龙四张的对应关系：

- `_idle` —— 侧身举手（出现在门口）
- `_stare` —— 抱臂正视镜头（监控画面里正对着你）
- `_jumpscare` —— 脸部特写（跳杀铺满屏幕）
- `_blackout` —— 捧腹大笑（断电后从左门冒出来「收电费」，脑袋一闪一闪）

噜噜五张的对应关系：

- `_idle` —— 叉腰眯眼的全身像（**在走廊里走着时，监控画面里显示这张**）
- `_stare` —— 正面特写、大眼睛直视镜头（**跳杀也用它**）
- `_peek` —— 侧身探出头（门外默认显示这张）
- `_startled` —— 瞪眼张嘴、带汗滴（盯着它看的时候换这张）
- `_angry` —— 眯眼抿嘴的怒视（**它摸到门外时，监控画面里换成这张**）

原图放在仓库外，用脚本处理（去白边、alpha 归一化、按规范命名）后落盘：

```
python tools/import_character_art.py
```

换素材时改脚本里的 `JOBS` 路径再重跑即可，幂等。

### 还是占位的部分

| 类别 | 内容 | 来源 |
|---|---|---|
| 背景 3 张 | `bg_office_front` / `_left_01` / `_right_01` | 程序生成 |
| 门片 4 张 | `ui_door_left_open` `ui_door_left_closed` `ui_door_right_open` `ui_door_right_closed` | 程序生成 |
| 环境音 3 条 | 风扇 / 电流嗡鸣 / 远处金属 | 程序合成 |
| 音效 7 条 | 脚步、开关门、开关灯、切监控、断电 | **Kenney**（CC0，可商用、无需署名） |

- 图与音都是脚本产出的，想调就重跑：`tools/gen_placeholder_art.py`、`tools/gen_placeholder_audio.py`
- Kenney 音效取自 `impact-sounds` 与 `interface-sounds` 两个包，源站 <https://kenney.nl/assets>，
  许可 **CC0 1.0**（公共领域）
- **还没做的**：牛来的立绘、监控画面（`mon_1a` ~ `mon_7`）、跳杀视频、UI 按钮图 ——
  这些暂时还是色块或代表色竖条，等你出图

有立绘的角色会直接显示立绘；没有的退回该角色的代表色竖条（至少能看出「有人在那儿」）。
剩下最值得先补的是**牛来的立绘**：有它才能看到它真的出现在右门口。
