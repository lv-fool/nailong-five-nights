# 生图提示词（角色姿势）

给项目作者用：把提示词丢进生图工具，出图后按文件名放进 `Assets/Art/Characters/`。

> ⚠️ **和 `docs/05-生图提示词.md` 不是一套画风，别混用。**
> 05 那份是**机位背景** —— 手绘绘本 / 水彩 / 低饱和冷灰。
> 这份是**角色立绘** —— **3D 渲染的卡通玩偶**（柔光、哑光塑料 / 绒面质感）。
> 拿 05 的风格块去出角色，会得到一只水彩画的狗。

## 〇、先看这段：通用规则

### 1. **必须用图生图，带参考图**

这条没有商量余地。`docs/03-素材规格.md` 第 153 行已经写过教训：

> 纯文生图会画成别的卡通动物

每条提示词下面都标了**参考图用哪张**。工具里把那张图作为参考上传，
提示词才生效。没有参考图的话，下面所有提示词都别用。

### 2. 身份锁定（每条都要带上）

中文：

```
完全保持参考图里这个角色的外形、比例、配色、材质和五官不变。
不要重新设计它，不要生成一只长得相似的其他角色。
只改变【姿势】和【镜头角度】这两件事。
```

English:

```
Keep exactly the same character as in the reference image — same body shape,
same proportions, same colors, same material, same face. Do NOT redesign it
and do NOT synthesize a similar-looking replacement. Change ONLY the pose and
the camera angle.
```

**为什么单独列**：生图模型看到长提示词时容易"顺手"把角色也重画一遍
（比如给奶龙加个尾巴、把牛来的眼睛画圆）。把"只改姿势和角度"写死，
跑偏率低很多。

### 3. 角色风格块（每条都拼上）

中文：

```
3D 渲染的卡通玩偶，皮克斯 / 广告 CG 质感，表面柔光、边缘圆润，
材质是哑光塑料或短绒布，光照柔和均匀、阴影很淡。
纯色背景（纯绿 #00FF00），脚下没有影子，背景没有渐变、没有地面、没有道具。
轮廓干净锐利，没有飞边、没有毛发散边、没有半透明边缘。
角色完整在画面内，不被裁掉任何部分。没有文字、没有水印、没有边框。
```

English:

```
3D rendered cartoon plush character, Pixar / CG advertising quality, soft
matte plastic or short-fur surface, rounded edges, gentle even lighting with
very soft shadows. Isolated on a solid pure green background #00FF00 — no
ground shadow, no gradient, no floor, no props. Clean crisp silhouette, no
fuzzy edges, no stray fur, no semi-transparent rim. The whole character fits
inside the frame, nothing cropped. No text, no watermark, no border.
```

### 3.1 为什么强制纯绿背景

项目要的是**透明 PNG 立绘**。绿幕是最省事的做法：

- 角色身上没有任何一处是纯绿（奶龙眼睛是青绿、不是 #00FF00），色度键能干净抠掉
- 出图后按 `四.1` 入库（alpha 归一化 + 裁到贴边由 `import_character_art.py` 做，
  但**色度键它不做**，得靠生图工具自己导出透明背景）
- 如果你的工具支持直接导出透明背景，那就更好，跳过色度键这一步

```
# 入库（会自动做 alpha 归一化 + 裁边）
python tools/import_character_art.py
```

⚠️ **牛来是绒面质感**，边缘有细毛。绿幕抠这种边缘容易留绿边或把毛边啃掉。
所以牛来那几条额外要求「边缘锐利、毛发不外散」；如果实在抠不干净，
改用**纯品红 #FF00FF** 背景重出一次（牛来身上也没有品红）。

### 4. 构图与比例（**这条决定进游戏后大小对不对**）

运行时是**按高度**铺立绘的（监控里 380 设计像素、门口约 1.8m），
所以**同一只角色在不同房间必须保持相近的高/宽比**，否则一进监控
「换个房间就变胖/变瘦」。

| 角色 | 现有 idle 的高/宽比 | 新图要控制在这个范围 |
|---|---|---|
| 奶龙 | 1.15 | **1.0 ~ 1.3** |
| 袋鼠 | 1.11 | **1.0 ~ 1.3** |
| 牛来 | 2.03 | **1.7 ~ 2.2**（细长，别画成矮胖） |
| 噜噜 | 1.39 | **1.2 ~ 1.6** |

另外：**内容要占满画布高度的 90% 以上**（上下留白会被裁掉，但留太多会显得人小）。

### 5. 命名（放对名字就自动生效，不用改代码）

```
char_<角色代号>_mon_<房间代号>.png
```

角色代号固定四个：`nailong` / `daishu` / `niulai` / `lulu`
房间代号（照官方 CAM）：

| 房间代号 | 机位 |
|---|---|
| `mon_1a` | 舞台 |
| `mon_1b` | 餐厅 |
| `mon_1c` | 海盗湾 |
| `mon_2a` | 西走廊 |
| `mon_2b` | 西转角 |
| `mon_3` | 储藏室 |
| `mon_4a` | 东走廊 |
| `mon_4b` | 东转角 |
| `mon_5` | 后台 |
| `mon_7` | 厕所 |

**机制说明**（`PrototypeScene.RoomPoseFileName` + `AssetBinder.LoadCharacters`）：

- 跑菜单「奶龙 / 5. 接入素材」会自动扫这 10 个文件名，**有就接、没有退回 idle**
- 所以**补一张生效一张，一行代码都不用改**，也不必一次画满 40 张
- 优先级：明确指定的姿态（偷电 / 探头 / 受惊…）> 房间专属图 > idle

## 四、交付检查清单

每张图入库前对一遍：

- [ ] **角色和参考图是同一只**（五官、配色、比例没跑偏）—— 这条最重要
- [ ] 背景是纯绿（或纯品红），脚下没影子
- [ ] 角色完整在画面内（除了第 6、10 两条刻意裁的）
- [ ] 高/宽比在该角色的允许范围内（见 `〇.4 表）
- [ ] 内容占画布高度 ≥ 90%
- [ ] 边缘干净，没有绿边残留、没有啃掉的毛边
- [ ] 文件名照 `〇.5` 写对
- [ ] 入库方式见下面 `四.1`（`import_character_art.py` **不会自动扫新文件**）

---

### 4.1 入库方式（二选一）

`tools/import_character_art.py` 里的 `JOBS` 是**硬编码的 (源图, 目标名) 列表**，
它**不会自动扫描新文件**。所以：

**方式 A：图已经是透明 PNG、也已经裁到贴边** → 直接丢进
`Assets/Art/Characters/`，不用跑脚本。

**方式 B：图还带绿幕 / 四周有大片透明空白** → 在 `JOBS` 里加一行再跑：

```python
JOBS = [
    ...
    (r"D:/你的路径/daishu_mon_1b.png", "char_daishu_mon_1b"),
]
```

```powershell
& "C:\Users\DELL\.workbuddy-ai\binaries\python\envs\default\Scripts\python.exe" tools/import_character_art.py
```

脚本幂等，重复跑不会跑坏。它只做两件事：alpha 峰值归一到 255、裁掉四周全透明空白。
**色度键（绿幕→透明）它不做** —— 如果你的工具不能直接导出透明背景，
抠图这一步得在生图工具里做，或者告诉我，我补一段色度键处理进脚本。

## 五、入库之后（我这边做的事）

图放对位置、跑一次「奶龙 / 5. 接入素材」就生效，**代码不用改**。

我这边还剩两件代码活（和素材无关，可以单独做）：

1. **门口立绘左右镜像** —— `ShowWorldCharacter` 收了 `side` 参数但没用它翻转，
   现在左门右门朝向一样。改 `localScale.x` 取负即可，按角色可关
   （带方向性的图不翻）。
2. **校验脚本** `tools/check_character_art.py` —— 检查新入库的图
   有没有 alpha、是否裁到贴边、高宽比是否偏离该角色 idle 超 30%、尺寸是否过大。

## 六、不用做的事

- **不要重画现有 14 张立绘** —— 风格以它们为准，我们是往里补图
- **不要给每只角色画满 10 个房间** —— 缺的自动退回 idle，按上面优先级补就行
- **不要画道具 / 家具进立绘** —— 背景纯绿，椅子桌子是场景的事，画进去会穿帮
