# 生图提示词（占位背景 → 真素材）

这份文件是给绿子用的：**把下面每一条提示词丢进生图工具，出图后按文件名放进项目即可**。

程序现在跑的那套背景是脚本渲出来的占位（`tools/gen_placeholder_art.py`），
丑但位置准。这份文件就是把它换成手绘/生成的真素材。

---

> ⚠️ **2026-10-14 晚：办公室背景的方案变了，这份文件只有「监控机位」那部分还完全适用。**
>
> 办公室已经不再是「若干张视角帧」，而是**一条圆柱全景**
> （`Assets/Resources/office_pano.png`，5120×1296，覆盖 ±145°，由
> `tools/render_pano.py` 用我们自己的光线投射渲染器产出）。转头是相机绕着中轴
> **真的转**，不是图片在交叉淡化（你当时说的「不是转场动画，而是真正的镜头转动」）。
> 出的图由程序按相机参数、光照、透视算出来，所以位置准、左右一致、和门片立绘对得上。
>
> 所以：**想换办公室氛围图，现在最省事的做法是把 `office_pano.png` 直接换掉**
> （尺寸 / 覆盖角度照旧，或者先告诉我，我把 `render_pano.py` 的参数改一版）。
> 下面「一、办公室」那些按 `bg_office_*.png` 命名的提示词，已经不再被项目读取，
> 留着只作构图参考。**下面的「二、监控机位」照旧有效。**

## 〇、先看这段：通用规则

### 1. 每条提示词前面都拼上这个「风格块」

**中文风格块**

```
第一人称视角的夜间室内场景，废弃的家庭披萨店，2D 手绘游戏背景，
预渲染的点击式恐怖游戏风格，冷蓝灰低饱和主调，只有少量暖黄 / 橙色的灯光，
低照度、强暗角、细颗粒噪点、轻微脏污与磨损，氛围诡异压抑。
画面里没有任何人物、动物或吉祥物。没有文字、没有水印、没有 UI、没有边框。
```

**English style block**

```
First-person night-time interior, an abandoned family pizza restaurant,
2D hand-painted point-and-click horror game background, pre-rendered,
cold desaturated blue-grey palette with only sparse warm amber light pools,
low-key lighting, heavy vignette, fine film grain, grimy worn surfaces,
eerie and oppressive. Completely EMPTY — no people, no characters, no mascots,
no text, no watermark, no UI, no border.
```

### 2. 通用负面提示词

```
人物, 动物, 吉祥物, 文字, 字母, 水印, logo, 边框, UI, 亮色调, 白天,
过曝, 高饱和, 卡通描边, 3D 渲染感, 景深虚化, 运动模糊
```

```
people, characters, mascots, animals, text, letters, watermark, logo, border,
UI, bright lighting, daytime, overexposed, oversaturated, cel-shading,
3D render look, depth of field blur, motion blur
```

### 3. 硬性规格

| 项 | 要求 |
|---|---|
| 尺寸 | **1920 × 1080**（16:9）。工具只出别的比例的话，出 16:9 再等比缩到 1920×1080 |
| 格式 | PNG（暗部多的图别用 JPG，压缩块很明显） |
| 画面内容 | **空房间** —— 角色是代码叠上去的，图里不要画 |
| 光照 | **暗**。宁可欠曝，代码里不会再加亮 |

### 4. 关于「像不像原版」

我们不是复刻 FNAF 的素材（那是别人的版权），是**照它的构图和调性**做我们自己的。
所以海报、儿童画、吉祥物这些，**画我们自己的奶龙 / 牛来 / 袋鼠 / 噜噜**，别照搬原版的角色。

## 一、办公室（最要紧的一组）

办公室是**唯一会转动镜头**的场景，所以它要出一组**同一间屋子、同一个光照、
只是镜头水平转了不同角度**的图。

代码用的是**逐帧序列**（每侧 10 帧走完 90°），文件名的 `01`~`10` 就是
「从正面转过去的第一帧…第十帧」。中间帧越准，转起来越顺。

> **怎么保证一致性**：先出 `bg_office_front.png`（正面），
> 后面每一张都**拿正面那张当参考图**（图生图 / 参考图 / 保持场景），
> 提示词里只改「镜头水平旋转多少度」。这是整组里唯一靠谱的做法 ——
> 纯文生图每次都出一间新屋子。

### 1.1 办公室 · 正面 `bg_office_front.png`（镜头 0°）

**中文**


## 四、优先级

1. **`bg_office_front.png`** —— 玩家 90% 的时间在看它
2. **`bg_office_left_10.png` / `bg_office_right_10.png`** —— 两扇门，最紧张的时刻
3. 中间的 18 张过程帧 —— 转头的顺滑度全靠它们
4. `mon_1b` 餐厅 / `mon_2a` 西走廊 / `mon_4a` 东走廊 —— 最常看的三个机位
5. 剩下的监控机位
