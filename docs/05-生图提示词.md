## 〇、先看这段：通用规则

### 1. 风格块（全项目统一，每条提示词都拼上它）

**中文风格块**

```
手绘绘本风格，水彩加水粉质感，笔触可见、纸面有颗粒；
第一人称视角的夜间室内，废弃的家庭披萨店；
低饱和的冷灰主调，只有少量暖黄 / 橙色的灯光；
低照度、强暗角、细颗粒噪点，表面脏污磨损，氛围诡异压抑。
画面里没有活人，也没有多余的动物或角色（例外见第 1.2 条）。
没有文字、没有水印、没有 UI、没有边框。
```

**English style block**

```
Hand-painted storybook illustration, watercolour and gouache, visible brush
strokes, paper grain. First-person night-time interior of an abandoned family
pizza restaurant. Desaturated cool grey palette with only sparse warm amber
light pools. Low-key lighting, heavy vignette, fine film grain, grimy worn
surfaces, eerie and oppressive. Completely EMPTY — no living people, no stray
animals or characters. No text, no watermark, no UI, no border.
```

### 1.1 风格词只写在风格块里

每间屋子的段落**只描述「这间屋子有什么」和「这间屋子自己的灯」** ——
别再往段落里塞「手绘」「水彩」「低饱和」「噪点」这类词。各写各的就会跑偏，
十条出来十种画风。

这一套和办公室是**同一套**（见 `docs/06-手绘贴图.md`）：监控画面和办公室
是同一家餐厅，画风必须一致。

### 1.2 唯一的例外：玩偶

风格块说「没有多余的动物或角色」，但有两处**必须画玩偶**，因为它们是陈设、不是角色：

- **CAM 1A 舞台** —— 台上那三只玩偶
- **CAM 5 后台** —— 架子上那几个空头套

这两条的提示词里已经写明了。其它机位一律空房间。

### 2. 通用负面提示词

```
人物, 动物, 吉祥物, 文字, 字母, 水印, logo, 边框, UI, 亮色调, 白天,
过曝, 高饱和, 卡通描边, 3D 渲染感, 景深虚化, 运动模糊
```

```
people, characters, mascots, animals, text, letters, watermark, logo, border,
UI, bright lighting, daytime, overexposed, oversaturated, cel-shading,
3D render look, depth of field blur, motion blur
```

### 3. 硬性规格

| 项 | 要求 |
|---|---|
| 尺寸 | **1920 × 1080**（16:9）。工具只出别的比例的话，出 16:9 再等比缩到 1920×1080 |
| 格式 | PNG（暗部多的图别用 JPG，压缩块很明显） |
| 画面内容 | **空房间** —— 角色是代码叠上去的，图里不要画 |
| 光照 | **暗**。宁可欠曝，代码里不会再加亮 |

### 4. 关于「像不像原版」

我们不是复刻 FNAF 的素材（那是别人的版权），是**照它的构图和调性**做我们自己的。
所以海报、儿童画、吉祥物这些，**画我们自己的奶龙 / 牛来 / 袋鼠 / 噜噜**，别照搬原版的角色。

## 一、办公室（已不用，仅作构图参考）

办公室是**唯一会转动镜头**的场景，所以它要出一组**同一间屋子、同一个光照、
只是镜头水平转了不同角度**的图。

代码用的是**逐帧序列**（每侧 10 帧走完 90°），文件名的 `01`~`10` 就是
「从正面转过去的第一帧…第十帧」。中间帧越准，转起来越顺。

> **怎么保证一致性**：先出 `bg_office_front.png`（正面），
> 后面每一张都**拿正面那张当参考图**（图生图 / 参考图 / 保持场景），
> 提示词里只改「镜头水平旋转多少度」。这是整组里唯一靠谱的做法 ——
> 纯文生图每次都出一间新屋子。
