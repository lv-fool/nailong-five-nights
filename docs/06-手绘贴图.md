# 手绘贴图（AI 出纹理，几何仍由程序控制）

办公室的观感靠这 5 张贴图。它们由 AI 生成（水彩 + 水粉笔触的手绘绘本风），
但**几何一个像素都没交给 AI** —— 房间、桌子、门洞、画框的位置还是
`tools/gen_placeholder_art.py` 算出来的。换贴图只换观感，不动结构。

> 为什么不让 AI 直接画整张画面：试过。图生图确实能把风格换过去，大结构也保得住
> （地面线误差 0.9%、桌子顶边 3%），但**墙上的画框、门洞、显示器这些会错位**
> （底图边缘只有 62.7% 能在结果图 ±2px 内找到对应）。我们的约定是「门片必须和
> 门洞严丝合缝、门口立绘按门心对齐」，门洞偏 3% 立绘就站偏了 —— 所以画面结构
> 必须由程序说了算，AI 只负责纹理。

## 一、5 张贴图

放 `tools/handpainted/`，都是 1024×1024：

| 文件 | 用在哪 |
|---|---|
| `wall.png` | 房间墙面 |
| `floor.png` | 地板（黑白棋盘砖） |
| `concrete.png` | 门外走廊 |
| `metal.png` | 卷帘门、风扇、音箱等金属件 |
| `paper.png` | 后墙海报、儿童画 |

`tools/cc0/` 那套照片写实贴图（ambientCG，CC0）**保留着没删**，想换回去把
`gen_placeholder_art.py` 的 `TEX_DIR` / `TEX_FILES` 指回 `cc0` + `.jpg` 即可。

## 二、生成要求（prompt 要点）

贴图会被 `load_textures()` 缩到 512×512，再由 `texel()` 用 `mod(u, 1)` **自动平铺**，
所以**必须能无缝重复**。prompt 里这几句是关键的：

- `Seamless tileable texture, ... The pattern must repeat seamlessly edge to edge in every direction.`
- `flat top-down orthographic view` —— 正交俯视，别有透视
- `Even uniform lighting across the entire image, absolutely no shadows, no vignette, no gradient, no border`
  —— **明暗必须交给渲染器的光照算**，贴图自己带明暗的话，贴到墙上会和光照打架
- 风格词固定成一套（`hand-painted, watercolor and gouache, visible brush strokes,
  storybook illustration style, desaturated muted palette`），5 张共用，风格才统一

实测 AI 对 `seamless tileable` 的理解不错：墙面那张的平铺接缝只有内部的 1.0~1.3 倍
（比值 1.0 就是完全看不出接缝）。

## 三、两道后处理

生成完不能直接用，有两个坑要处理：

### 1. 棋盘格要对齐贴图边界

`floor.png` 是黑白棋盘，如果格子没落在贴图边界上，平铺时格子节奏会错乱
（相邻两块拼起来出现半个格子）。做法是**检测格线 → 裁出整数个格子 → 缩放回原尺寸**：

- 用亮度剖面的**突变点**找格线位置（阈值取最大梯度的 50%，相邻的合并）
- 从第一条格线裁到最后一条 → 正好是整数格
- **格数必须是偶数** —— 奇数的话平铺后会出现两个同色格相邻
- 实测：原图格线在 106/254/406/557/710/860/1009，裁 `[106:1009] × [135:996]`
  （6×6 格）缩回 1024，格线就正好落在 0 和 1022 上了

⚠️ 别用自相关找周期 —— 棋盘的自相关周期是 **2 格**（黑白反相），不是 1 格，
会算错一半。

### 2. 接缝复检

裁切/缩放之后要重新量一遍边缘差异，确认没引入新接缝。
指标：`|右边缘列 − 左边缘列|` 和内部的相邻列差比一比，比值接近 1 就对了。

> 地板这个比值会偏高（3~5 倍），**是正常的** —— 格线正好压在贴图边界上，
> 边界两侧本来就是黑格和白格。看平铺预览图确认视觉连续即可。

## 四、改完怎么重渲

```bash
PY=python
$PY tools/gen_placeholder_art.py     # 门板贴图 door_face_*.png + 门片
$PY tools/render_pano.py             # 全景条 office_pano.png
```

然后回 Unity 跑一次「奶龙 → 5. 接入素材」（或 `AssetDatabase.ImportAsset(..., ForceUpdate)`），
**必须强制重导入** —— 否则 Unity 还用着旧贴图渲出来的旧全景。
