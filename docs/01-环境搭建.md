# 01 · 环境搭建

> 实际走过的路径（2026-10-11）：Unity Hub 已装好，编辑器装 **2022.3.62f3c1**。
> 下面是记录，也是换机器时的复现步骤。

---

## 一、Unity Hub（已装）

Unity Hub 是 Unity 的版本管理器，编辑器本体通过它安装。

**直链**（实测 126 MB，走国内 CDN，下载很快）：

```
https://public-cdn.cloud.unity3d.com/hub/prod/UnityHubSetup.exe
```

首次启动会要求登录 Unity 账号，个人版（Personal）免费。

> 这个链接会重定向到 `public-cdn.cloud.unitychina.cn`，也就是**中国版 Hub**。
> 中国版 Hub 的版本停在 **3.3.6**，比全球版旧不少 —— 这一点直接决定了下面编辑器的选择。

## 二、Unity Editor：2022.3.62f3c1

本项目使用 **Unity 2022.3 LTS**（`2022.3.62f3c1`，中国版）。

### 为什么不是 Unity 6

原本打算用 Unity 6.3 LTS，但**中国版 Hub 3.3.6 拿不到 Unity 6 的版本列表** ——
实测它拉的版本接口只返回 3 条记录。要装 Unity 6 只能手动下 3.9 GB 安装包、装完再让
Hub 识别，绕一大圈。

而 2022.3 LTS 做这个项目**没有任何短板**：

- 2D 静态图 + 热点交互，不吃引擎新特性
- 中文教程绝大多数基于 2022.3，遇到问题最好搜
- 中国版 Hub 原生支持，零折腾

代价是 2022.3 LTS 已接近支持周期末尾，不再有官方修复 —— 但**已装好的编辑器永久可用**，
对业余项目没有实际影响。

### 实际安装情况（2026-10-11）

| 项 | 值 |
|---|---|
| 编辑器路径 | `D:\unity\2022.3.62f3c1` —— **自定义路径**，不是默认的 `C:\Program Files` |
| changeset | `1623fc0bbb97` |
| 已装模块 | 编辑器本体 + **WebGL Build Support** + 离线文档 |
| 未装模块 | Windows Build Support (IL2CPP) |

**IL2CPP 暂时不影响开发** —— 编辑器里运行用 Mono 后端，不需要它。等要正式打包
Windows 客户端时再补：Hub → 安装 → 该版本右侧齿轮 → 添加模块。

> ⚠️ **版本号必须一字不差**。Hub 里的编辑器版本和项目 `ProjectSettings/ProjectVersion.txt`
> 只要差一个字符，Hub 就会报"缺少编辑器版本"、拒绝打开。
> 本机实际装的是 `2022.3.62f3c1`（第 62 补丁），注意别写成 `2022.3.6f3c1`（第 6 补丁）。

### 如果以后要换 Unity 6

Windows x64 安装包直链（3.92 GB）：

```
https://download.unity3d.com/download_unity/de8167e7440c/Windows64EditorInstaller/UnitySetup64-6000.3.26f1.exe
```

装完后 Hub → **Installs → Add** 指向安装目录即可识别。项目打开时 Unity 会提示版本
升级，接受就行（YAML 资产自动迁移）。

## 三、磁盘空间

| 盘符 | 可用 | 说明 |
|---|---|---|
| C: | 105 GB | 装 Unity Hub + Editor 足够（需 ~10 GB） |
| D: | 38 GB | 项目与构建产物放这里，注意 Unity 的 `Library/` 缓存会随项目增长 |

> `Library/` 文件夹是 Unity 的本地缓存，动辄几个 GB，**已在 .gitignore 中排除**，
> 不会进版本库。删掉它不会丢东西，只是下次打开项目要重新导入一遍。

## 四、打开项目

Editor 装好后：

1. Unity Hub → **Projects** → **Add** → **Add project from disk**
2. 选中 `D:\GitHub\奶龙的五夜后宫`
3. 点开。首次打开会花几分钟做资源导入和包解析（正常现象）。
4. 打开后菜单栏会多出一项 **`奶龙`** —— 那是本项目自带的编辑器工具，
   跑一次里面的初始化命令即可把渲染、输入、构建等设置配好。
   （工具脚本在 `Assets/Editor/ProjectSetup.cs`）

## 五、关于中文路径的提醒

项目路径 `D:\GitHub\奶龙的五夜后宫` 含中文。Unity 2022.3 对 UTF-8 路径的支持基本够用，
日常开发没问题，但仍有小概率在这些场景踩坑：

- 某些第三方插件解析路径失败
- 命令行构建 / CI 流程报编码错误
- 部分构建目标（如 IL2CPP + 特定平台）对非 ASCII 路径敏感

**目前先按现状用**。如果之后真的撞上这类报错，再把项目挪到纯英文路径
（例如 `D:\GitHub\naelong-five-nights`），并在 Hub 里重新 Add 一次即可，
代码和资产都不受影响。
