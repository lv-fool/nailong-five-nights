# 01 · 环境搭建

> 下面是补齐环境的完整步骤。装完才能打开本项目。

## 一、装 Unity Hub

Unity Hub 是 Unity 的版本管理器，编辑器本体通过它安装。

1. 打开 https://unity.com/download ，下载 **Unity Hub**（Windows 版）。
2. 安装时保持默认路径（`C:\Program Files\Unity Hub`）。
3. 首次启动会要求登录 Unity 账号。没有就注册一个 —— 个人版（Personal）免费，
   年收入 20 万美元以下都可以用，功能与付费版没有区别。

> 如果命令行更顺手，也可以用 winget：
> ```powershell
> winget install --id Unity.UnityHub -e
> ```

## 二、装 Unity Editor 6.3 LTS

本项目锁定 **Unity 6.3 LTS（6000.3.26f1）**。理由：LTS 是长期支持线，API 冻结、
只修 bug 不加功能，适合要持续几个月做完的项目。

在 Unity Hub 里：

1. 左侧选 **Installs（安装）** → 右上角 **Install Editor**。
2. 切到 **Archive（归档）** 页签，找到 **6000.3.26f1** 并安装。
   - 如果列表里只有更新的 6.6 版本，也可以装 6.6 —— 项目打开时 Unity 会提示
     升级版本，接受即可（YAML 资产会自动迁移，风险很低）。
3. **必选模块**（安装向导里的 "Add modules"）：
   - ✅ **Windows Build Support (IL2CPP)** —— 导出 Windows 客户端必须
   - ✅ **Documentation** —— 离线 API 文档，很有用
   - ⬜ WebGL Build Support —— 可选，想发布网页版再加
   - ⬜ Android / iOS —— 本项目不需要
4. 安装体积约 **6–8 GB**，耗时 20–60 分钟，取决于网速。

## 三、磁盘空间

| 盘符 | 可用 | 说明 |
|---|---|---|
| C: | 105 GB | 装 Unity Hub + Editor 足够（需 ~10 GB） |
| D: | 38 GB | 项目与构建产物放这里，注意 Unity 的 `Library/` 缓存会随项目增长 |

> `Library/` 文件夹是 Unity 的本地缓存，动辄几个 GB，**已在 .gitignore 中排除**，
> 不会进版本库。删掉它不会丢东西，只是下次打开项目要重新导入一遍。

## 四、打开项目

Editor 装好后：

1. Unity Hub → **Projects** → **Add** → **Add project from disk**
2. 选中 `D:\GitHub\奶龙的五夜后宫`
3. 点开。首次打开会花几分钟做资源导入和包解析（正常现象）。
4. 打开后菜单栏会多出一项 **`奶龙`** —— 那是本项目自带的编辑器工具，
   跑一次里面的初始化命令即可把渲染、输入、构建等设置配好。
   （工具脚本在 `Assets/Editor/ProjectSetup.cs`）

## 五、关于中文路径的提醒

项目路径 `D:\GitHub\奶龙的五夜后宫` 含中文。Unity 6 对 UTF-8 路径的支持已经比较完善，
日常开发基本没问题，但仍有小概率在这些场景踩坑：

- 某些第三方插件解析路径失败
- 命令行构建 / CI 流程报编码错误
- 部分构建目标（如 IL2CPP + 特定平台）对非 ASCII 路径敏感

**目前先按现状用**。如果之后真的撞上这类报错，再把项目挪到纯英文路径
（例如 `D:\GitHub\naelong-five-nights`），并在 Hub 里重新 Add 一次即可，
代码和资产都不受影响。
