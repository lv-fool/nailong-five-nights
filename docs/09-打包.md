# 09 · 打包一个能发给别人的 Windows 版

> 写于 2026-10-19。产物已验证：双击能跑、能进永夜模式、HUD 与记点逻辑正常。

## 一、怎么打包

**菜单方式**：Unity 菜单栏 → **奶龙 / 10. 打包 Windows 版**

**命令行方式**（不开图形界面也能打）：

```powershell
Remove-Item Env:HTTP_PROXY,Env:HTTPS_PROXY,Env:http_proxy,Env:https_proxy,Env:ALL_PROXY -ErrorAction SilentlyContinue
$argline = '-batchmode -quit -projectPath "F:\nailong f" ' +
           '-executeMethod NailongFNAF.EditorTools.BuildWindows.Build ' +
           '-logFile "F:\nailong f\.setup\build.log"'
Start-Process -FilePath 'F:\Unity\2022.3.62f3c1\Editor\Unity.exe' -ArgumentList $argline
```

日志里搜 `BUILD-OK`（成功，带产物路径、体积、耗时）或 `BUILD-FAIL`（失败原因）。
命令行失败时进程退出码是 1。

产物固定在 `Builds/Windows/`（`Builds/` 已在 `.gitignore` 里，不入库）：

| 文件 | 大小 | 说明 |
|---|---|---|
| `NailongFiveNights.exe` | 0.6 MB | 启动器，双击它 |
| `UnityPlayer.dll` | 30 MB | 引擎本体 |
| `NailongFiveNights_Data/` | 223 MB | 资源、脚本、StreamingAssets 里的 4 条跳杀 mp4 |
| `MonoBleedingEdge/` | 9 MB | Mono 运行时 |
| `UnityCrashHandler64.exe` | 1.1 MB | 崩溃弹窗（可删） |

合计约 **263 MB**，压成 zip 约 **116 MB**。

## 二、发给别人时注意什么

- **整个文件夹一起发**，不能只发 exe；收的人不用装 Unity，解压双击即可
- 系统要求：Windows 10 / 11 64 位，显卡支持 DX11
- 默认 1600×900 窗口、可拉伸；原始设置是 1920×1080 全屏窗口
- **exe 没有代码签名**，别人第一次运行可能被 SmartScreen 拦一下（「更多信息 → 仍要运行」）
- 存档（解锁的夜晚、永夜模式最佳纪录）按 Unity 默认放在
  `C:\Users\<用户名>\AppData\LocalLow\NailongStudio\奶龙的五夜后宫\`
- 想换货时删掉 `Builds/Windows` 重新打一次即可，游戏本体完全可再生

## 三、为什么是 Mono 而不是 IL2CPP

本机装的编辑器**只带了 Windows Mono 变体**：`Editor/Data/PlaybackEngines/WindowsStandaloneSupport/Variations/`
下只有 `mono`、`win32_player_*`、`win64_player_*`，没有 IL2CPP 的 win64 变体。
所以 `BuildWindows.Build` 里显式写了：

```csharp
PlayerSettings.SetScriptingBackend(BuildTargetGroup.Standalone, ScriptingImplementation.Mono2x);
```

要换 IL2CPP，得先用 Hub 补装 **Windows Build Support (IL2CPP)** 模块，
再把这一行改成 `ScriptingImplementation.IL2CPP`。Mono 的副作用是
`Assets/Scripts` 下的代码都能被反编译 —— 自己玩、发朋友玩没影响。

## 四、体积还能怎么压

大头是 `NailongFiveNights_Data/sharedassets0.assets.resS`（139 MB）——
场景里的贴图按默认导入设置进了包，没走压缩格式。想瘦身可以从这几处动：

- 把 `Assets/Art` 下的大图改成压缩格式（BC7 / DXT5），只在需要透明度的地方保留 alpha
- 环境音 `amb_*.wav`（各 2.5 MB）本来就是占位音，换成 ogg 能省一半
- 跳杀 mp4（合计 14 MB）已经在 StreamingAssets，保持不动最好 —— 它不进 `resS`

改完记得重新跑一遍 EditMode 测试和 `-playSmoke` 冒烟，确认没把画面弄坏。

## 五、打完包该验什么

最少这三条（我这次就是这么验的）：

1. 双击 exe，标题页三个按钮（开始游戏 / 永夜模式 / 退出）都在
2. 点「永夜模式」进办公室，左下角出现 `永夜 · 已撑 0 小时 · M 秒后补 X% · 危险 D/6`
3. 点几下门 / 手电筒，那行的「还差 N 点」要变小

更细的自动化验证见 `docs/08-无头验证.md`（`-playSmoke` 探针）。注意探针是
`#if UNITY_EDITOR` 的，**只在编辑器 Play 模式跑，不进玩家包体**。
