## 已定的设计

**完整定稿见 `docs/04-设计决策.md`**，这里只列要点：

| 问题 | 结论 |
|---|---|
| 视角操作 | 鼠标移到屏幕左右边缘就转头（FNAF 原作做法） |
| 门 | 点一下切换（不是按住），画成**叠层门片** |
| 美术调性 | 可爱反差恐怖 —— 保留奶龙的可爱外形，靠氛围、音效、突然逼近吓人 |
| 目标平台 | 只做 Windows（WebGL 模块已装，以后想加随时能加） |
| 夜数结构 | 五夜 + 隐藏夜（通关第 5 夜解锁）；一夜 8 分 30 秒 |
| 敌人 | **四个，各管一种手段** —— 牛来/袋鼠（关门挡）、噜噜（开灯+盯门外 2 秒）、奶龙（不管就偷电，看监控即止） |
| 监控机位 | 先做 3 个（大厅 / 左走廊 / 右走廊），代码按配置数组，可扩 |
| 跳杀 | VideoPlayer 播 4 条专属 mp4，视频没就绪时用静态惊吓图兜底 |
| 难度 | 一张可配表（ScriptableObject），每夜 × 每个敌人一个活动度数值 |
| 中文字体 | 思源黑体（SIL OFL，可随包分发） |

## 原型怎么玩

菜单「奶龙 → 4. 搭建可玩原型」，然后按 Play：

- 鼠标移到屏幕**左右边缘** → 左右转头
- 底部按钮 → 开关左右门 / 灯，切换监控
- 监控开着时按 **1 / 2 / 3** → 切换机位（大厅 / 左走廊 / 右走廊）
- **R 键** → 重开一夜
- **[ / ] 键** → 上一夜 / 下一夜（调难度用）

四个敌人已经跑起来了：牛来摸左门、袋鼠摸右门（关门挡），噜噜蹲在门外（开灯 + 盯着那一侧 2 秒），
奶龙蹲在某个机位偷电（切到它所在机位看一眼）。画面左下角能看到每个敌人当前的位置与活动度。

画面现在是纯色块，只为了验证玩法。真素材按 `docs/03-素材规格.md` 的命名放进 `Assets/Art/` 即可替换。
