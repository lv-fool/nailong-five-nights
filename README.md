## 开始之前

Unity Hub（中国版 3.3.6）与编辑器 2022.3.62f3c1 已装好，细节见 `docs/01-环境搭建.md`。

用 Hub 打开本目录后，菜单栏会出现「奶龙」：

| 菜单项 | 作用 |
|---|---|
| 1. 初始化项目设置 | 分辨率、色彩空间、公司 / 产品名 |
| 2. 生成主场景骨架 | 相机 + UI 画布 + 事件系统 |
| 3. 检查并补全目录 | 缺哪个目录补哪个 |
| **4. 搭建可玩原型** | 往当前场景放好原型入口，按 Play 就能玩 |
| **5. 接入素材** | 把 `Assets/Art`、`Assets/Audio` 里的素材接到场景上（换素材后重跑一次） |

**Window → General → Test Runner → EditMode → Run All**

## 已定的设计

**完整定稿见 `docs/04-设计决策.md`**，这里只列要点：

| 问题 | 结论 |
|---|---|
| 视角操作 | 鼠标移到屏幕**左右各三分之一**就平滑转头（FNAF 原作做法） |
| 门 | 点一下切换（不是按住），画成**叠层门片**；按钮贴在两侧墙上，门在上、灯在下 |
| 美术调性 | 可爱反差恐怖 —— 保留奶龙的可爱外形，靠氛围、音效、突然逼近吓人 |
| 目标平台 | 只做 Windows（WebGL 模块已装，以后想加随时能加） |
| 夜数结构 | 五夜 + 隐藏夜（通关第 5 夜解锁）；一夜 8 分 30 秒 |
| 敌人 | **四个，各管一种手段** —— 袋鼠/牛来（关门挡）、噜噜（从正门来，用手电筒不停地闪）、奶龙（偷电 + 摸右门，看监控即止） |
| 监控机位 | 照官方平面图做满 **11 个**（1A ~ 7；CAM 6 厨房只有声音），代码按配置数组 |
| 跳杀 | VideoPlayer 播 4 条专属 mp4，视频没就绪时用静态惊吓图兜底 |
| 难度 | 一张可配表（ScriptableObject），每夜 × 每个敌人一个活动度数值 |
| 中文字体 | 思源黑体（SIL OFL，可随包分发） |

## 原型怎么玩

菜单「奶龙 → 4. 搭建可玩原型」，然后按 Play：

操作方式与界面布置对齐官方 FNAF 1 —— **纯鼠标**：

- 鼠标移到屏幕**左右各三分之一** → 平滑转头
- 点击**两侧墙上**的 **DOOR**（红）/ **LIGHT**（绿）→ 开关门与灯（门在上、灯在下）。
  **开着灯才看得见门外站着谁**，门关着也看不见
- 鼠标移到**屏幕底部边缘** → 升起 / 放下监控
- 监控升起后，点**右侧小地图**的 CAM 框 → 切机位
- **按住屏幕底部中间的 FLASHLIGHT** → 手电筒亮（松手就灭），照从正门摸进来的噜噜

调试快捷键（官方没有，留着调参用）：**1~9 / 0 / -** 切 11 个机位、**R** 重开一夜、**[ / ]** 换夜、
**F1** 显示 / 隐藏调试面板。

界面按官方摆放：**时钟在右上角**，**电量与 Usage 五格条在左下角**（起始 99%）。
Usage 亮几格就是当前耗电等级，颜色由绿转黄转红 —— 关一扇门、开一盏灯、升起监控，
每一样都让它多亮一格。

四个敌人已经跑起来了：袋鼠摸左门、牛来摸右门（关门挡），噜噜从**正门**摸进来
（拿手电筒不停地闪它，闪够 4 下退走），奶龙一边蹲机位偷电、一边摸右门。
按 **F1** 能看到每个敌人当前的位置与活动度。
（边的分配照 FNAF 1：袋鼠 = 邦尼走左、牛来 = 奇卡走右、奶龙 = 弗莱迪也从右来；
噜噜的击退照 2 代的狐狸 —— 闪一下逼退一步、闪够次数退走。）

**奶龙是唯一会两头使坏的**：它每偷到一次电，就沿右门那条路推进一步 —— 不管它，它迟早自己站到门口。
右门是它和牛来共用的通道，门口已经有人时，后来者停在走廊等（先来后到）。
应对还是老办法：切到它所在的机位看一眼，它就停手并换位。

**断电之后它还会来「收电费」** —— 这一段照 FNAF 1 原版的断电流程分三段走：
先是 2 秒纯黑，接着它从左门现形、**八音盒的托雷多进行曲**响起，脸跟着拍子一亮一暗
（拍点上看清它，其余时候沉进黑暗）；音乐一停画面彻底黑掉，只剩一个隐约的轮廓，
再过 2.5 秒就动手。整段 18 秒，期间门全弹开、灯灭、监控掉线、视角锁在正面，只能盯着它。

**奶龙已经有立绘了**：切到它所在的机位会看见它正对着镜头（它会愣 1.2 秒再换位，够你看清），
被抓时是全屏的跳杀特写，断电后是捧腹大笑的那张在闪。**噜噜的五张也齐了**（正前方、监控、受惊各就各位），
牛来 / 袋鼠还没图，
到门口时先用各自的代表色竖条代替 ——
按 `docs/03-素材规格.md` 的命名把图放进 `Assets/Art/Characters/`，再跑一次「奶龙 → 5. 接入素材」即可。

**背景与声音还是占位素材**：程序生成的暗色房间背景、卷帘门片，加上环境底噪与操作音效。
断电音乐是合成的八音盒版托雷多进行曲（`tools/gen_power_out_music.py`）——
原版用的采样有版权，这段是自己做的，曲谱本身是公有领域。
素材来源与许可见 `docs/03-素材规格.md` 第五节。
